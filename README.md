## 🚀 Featured Projects

### 🏦 SureD

**Blockchain-powered rental security deposit platform**

SureD is a platform designed to make rental security deposits more transparent and trustworthy by using blockchain-based escrow.

**Core concepts:**

* Smart-contract-based escrow
* Tenant–landlord deposit management
* On-chain transaction tracking
* Deposit funding and release workflow
* Multi-party rental deposit management in SureD 2.0

**Tech:** React · TypeScript · Tailwind CSS · Node.js · Express · MongoDB · Stellar · Soroban

🌐 **Live:** [sure-d.vercel.app](https://sure-d.vercel.app/)

---

### 🛰️ DepthWizard

**Single-View Height Estimation and 3D Flythrough**

A Smart India Hackathon project focused on estimating depth and generating 3D terrain representations from a single optical remote-sensing image.

**Pipeline:**

```text
RGB Image
   ↓
AI Depth Estimation
   ↓
Depth Map
   ↓
DSM Generation
   ↓
3D Flythrough
```

The project explores computer vision and depth-estimation techniques for disaster-management and remote-sensing applications.

**Tech:** Python · AI/Computer Vision · Depth Estimation · 3D Visualization
